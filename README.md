# Personal Portfolio – Assignment 1

## Project Description

This project is a responsive personal portfolio website created for Assignment 1: Foundation and AI Integration. It introduces me, presents two project ideas, and includes a contact form.

## Features

- About Me section
- Two project cards
- Contact form
- Responsive design for desktop, tablet, and mobile
- Smooth scrolling
- JavaScript confirmation message

## Technologies Used

- HTML
- CSS
- JavaScript
- Git and GitHub

## How to Run the Website

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The website will open in a browser.

No installation is required.
