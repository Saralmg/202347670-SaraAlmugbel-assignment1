# AI Usage Report

## Tools Used and Use Cases

I used ChatGPT during this assignment. It helped me plan the structure of the portfolio, write examples of HTML, CSS, and JavaScript, choose a color palette, and prepare the documentation. I also used it to explain the steps for creating and uploading the project.

## Benefits and Challenges

AI helped me complete the assignment more efficiently and understand how the different files connect. It was useful for learning about responsive design, CSS Grid, Flexbox, and JavaScript event listeners. One challenge was making sure that every suggestion matched the assignment requirements and was not unnecessarily complicated.

## Learning Outcomes

I learned how HTML creates the structure of a webpage, how CSS controls its appearance and responsive layout, and how JavaScript adds interactivity. I also learned how to organize a web project into separate folders and use GitHub to store and submit my work.

## Responsible Use and Modifications

I reviewed the AI suggestions and followed the development process step by step. I changed the personal information, project content, and visual style to fit my portfolio. I tested the navigation, responsive layout, project cards, and contact form to make sure the website worked correctly. I understand the main parts of the code and how they work.
